# Frontend Rules

- Reuse the existing design system and component patterns.
- Preserve accessibility, keyboard navigation, responsive behavior, and loading and error states.
- Avoid new state-management libraries unless required.
- Keep components focused.
- Extract shared code only when reuse or complexity justifies it.
- Test behavior rather than implementation details.
