# Implement

1. Read `docs/current-task.md` when present.
2. Search for existing patterns and identify minimum affected files.
3. State a plan of at most five bullets for non-trivial work.
4. Implement the smallest complete solution.
5. Add or update focused tests.
6. Run targeted checks first.
7. Report changed files, delivered behavior, checks run, and unresolved issues.
8. Do not perform unrelated cleanup.
