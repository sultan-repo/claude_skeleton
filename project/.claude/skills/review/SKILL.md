# Review

Prioritize findings by severity:
- blocker
- high
- medium
- low

For each finding provide:
- file and location
- concrete problem
- user or production impact
- recommended fix

Focus on defects and risk, not stylistic preferences. Confirm test coverage and compatibility. If no material issues exist, say so clearly.
