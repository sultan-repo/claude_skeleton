# Debug

1. Reproduce or characterize the failure.
2. Collect only relevant errors, logs, stack traces, and code paths.
3. Form ranked hypotheses.
4. Test the cheapest discriminating hypothesis first.
5. Identify the root cause before broad changes.
6. Apply the minimum fix.
7. Add a regression test.
8. Do not retry identical failed commands without new evidence.
