# Finish Task

1. Review the diff for unintended changes.
2. Run targeted tests and required lint, type, or build checks.
3. Run the full suite only when justified.
4. Confirm acceptance criteria.
5. Update relevant documentation or decisions.
6. Return only:
   - completed behavior
   - changed files
   - checks and results
   - remaining risks
