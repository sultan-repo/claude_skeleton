# Objective-First Decisions

- Every material decision must support the ultimate project objective.
- Inspect existing code and documentation before proposing significant changes.
- Challenge weak assumptions and incomplete requirements.
- Distinguish facts, assumptions, recommendations, risks, and unresolved questions.
- Recommend justified scope or requirement changes even when they differ from the current plan.
- Do not expand scope for novelty, theoretical completeness, or technical elegance alone.
- Present major direction changes for approval rather than implementing them silently.
