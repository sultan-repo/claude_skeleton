# Planning and Continuity

- Read the current plan, status, decisions, TODOs, deferred actions, risks, and blockers before substantial work.
- Break large work into independently implementable and verifiable milestones.
- Define measurable acceptance criteria and validation before implementation.
- Failed required validation blocks dependent work until resolved or appropriately accepted by the user.
- Do not silently abandon existing plans when a new request arrives. Incorporate, defer, reject, or replace previous direction explicitly.
- Update durable project memory and state the next action after substantial work.
